# RS-485 / Modbus migration summary

## Что изменено

- RS‑485 и Modbus RTU полностью перенесены с `v1.ino` (Nano) в `esp32_controller.ino` (ESP32).
- ESP32 использует `Serial2`:
  - `TX=GPIO17`
  - `RX=GPIO16`
  - направление `RE/DE=GPIO4`.
- Команды VFD (`run/stop`, `frequency`) и чтение обратной связи (ток/частота) теперь выполняются только на ESP32.

## Что осталось на Nano

- чтение уровней бака;
- чтение аналоговых сигналов (ток скважины, давление скважины/дома);
- управление реле скважинного насоса;
- простая телеметрия.

## Протокол между контроллерами

- Обмен переведён на I2C (`Nano` slave `0x10`, `ESP32` master).
- Nano отправляет только I/O телеметрию.
- ESP32 отправляет Nano только команду на реле скважины.
- Состояние VFD больше не передаётся через Nano.

## Эффект

- Устранено дублирование ответственности за VFD.
- Снижена зависимость работы VFD от Nano.
- Структура системы стала проще для сопровождения.
